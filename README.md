# Proyecto Tienda de Tenis - Agilismo

## Descripción

Proyecto desarrollado para aplicar la metodología Scrum y utilizar GitHub durante el desarrollo de una aplicación para una tienda de tenis.

## Objetivo

Desarrollar una aplicación que permita gestionar los productos de una tienda de tenis y aplicar los conceptos aprendidos sobre metodologías ágiles.

## Metodología

El proyecto se desarrollará utilizando la metodología ágil Scrum.
